# 2019-2020 Foundations

Period: 2019-02 to 2020-12  
Versioning status: no formal release versions yet

## Implemented functionality
- Core backend foundation was created with SQL schema, entity modeling, DAO/controller wiring, and initial event/user/picture APIs.
- Authorization and authentication foundations were introduced, including role-aware access behavior and early OAuth/basic auth flows.
- Public website shell was established with header/footer/navigation and early content pages.
- Event and calendar experiences were introduced and iterated quickly:
  - monthly event fetching,
  - event popups and event details,
  - all-day/event-time handling improvements,
  - loading and mobile usability improvements.
- Google Calendar integration was added and then refined multiple times for reliability and formatting behavior.
- News/blog display capability was introduced on frontend and connected to backend DTO-based news flows.
- Early membership page and association information pages (about/board/committees/contact) were added.
- File download capability through backend endpoints was introduced.

## Outcome
- The project moved from initial scaffolding to a functioning association platform with core event/news/calendar/member-facing website behavior.
