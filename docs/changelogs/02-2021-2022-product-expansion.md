# 2021-2022 Product Expansion

Period: 2021-01 to 2022-12  
Versioning status: no formal release versions yet

## Implemented functionality
- Calendar and event usability expanded significantly:
  - month/day/week views,
  - better handling of long titles and multiple events per day,
  - more stable time and timezone behavior,
  - improved retrieval performance and event visibility controls.
- Event management became a full workflow:
  - create/edit/delete endpoints and pages,
  - event manager and upcoming events pages,
  - sign-up forms with stronger validation.
- Event sign-up domain matured:
  - members-only constraints,
  - event sign-up UX improvements,
  - signup validation and form correctness checks.
- Committee and board operations matured:
  - committee manager flows,
  - committee membership/role updates,
  - board page refreshes and board data improvements.
- News/blog interaction matured:
  - article previews and pagination,
  - clickable/shareable article flows,
  - ordering and API response consistency improvements.
- Security model strengthened:
  - migration to JWT auth,
  - login/route guard behavior for protected pages,
  - expanded role/permission checks for management endpoints.
- Membership and account flows were improved:
  - membership form updates,
  - account enabling fixes,
  - more frontend form validation for profile/account paths.
- Richer event content support was added:
  - promo images,
  - markdown-to-HTML formatting for calendar/event descriptions.

## Outcome
- The platform evolved from a basic site into a management-capable product with stronger auth, richer event workflows, and better committee/member operations.
