# 2023 Transition and Containerization

Period: 2023-01 to 2023-12  
Versioning status: no formal release versions yet

## Implemented functionality
- Event and visibility behavior received continued refinement:
  - visible-event filtering,
  - past-event limits,
  - sign-up form stability updates.
- Member and board-facing UI continued to expand:
  - member view and member-manager related updates,
  - board information refreshes.
- Esports and content sections were expanded (including additional game-specific pages/features).
- Frontend upgrade path toward Vue 3 advanced (including significant vue3 branch work and compatibility fixes).
- Dockerization and local environment workflows were introduced and matured:
  - basic Docker setup,
  - compose setup for local full-stack runs,
  - frontend/backend container workflow fixes.
- Calendar v3 work started, including popup/component refactors and cleanup of event retrieval logic.

## Outcome
- The project entered a transition phase: modernizing the frontend stack and making local full-stack containerized development practical.
