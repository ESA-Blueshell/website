# 2026 Automated Releases

Entries below this heading are generated by release-please from Conventional
Commits subjects on `main`. Earlier periods were written by hand; see the index
in `CHANGELOG.md`.

Which types appear here:

- Shown: `feat`, `fix`, `perf`, `refactor`, `docs`, `build`, `revert`, and
  `style`. `style` is included because it is used here for visual changes a
  member can see, such as spacing, colour, or type rendering.
- Hidden: `ci`, `chore`, `test`. Code formatting and lint churn belong under
  `chore` rather than `style`, so they stay out of a changelog members read.
