# OpenAPI specs

The OpenAPI document this repository owns.

| File          | Source                                                   | Consumer                          |
| ------------- | -------------------------------------------------------- | --------------------------------- |
| `hornet.json` | Vendored Hornet bot API spec                             | (reserved for a future client)     |

The Blueshell spec itself lives at `services/api/openapi.yaml`, written by the
generator test with sorted keys and block-style YAML, and is regenerated by
`scripts/generate_openapi.sh`.

## Brevo and Discord

Their specs used to be vendored here and their clients generated by
`:libs:clients:*`. Both now live in repositories of their own:

- [ESA-Blueshell/brevo-client](https://github.com/ESA-Blueshell/brevo-client)
- [ESA-Blueshell/discord-client](https://github.com/ESA-Blueshell/discord-client)

Each fetches its upstream spec nightly, reduces it to the surface this estate
actually calls, classifies any change with `oasdiff` into a major, minor or
patch, and publishes a versioned client. Consuming a published package rather
than vendoring a spec means an upstream change arrives as a version bump with a
changelog, reviewed like any other dependency, instead of as a large diff
somebody has to interpret.

They are consumed from `services/api/build.gradle.kts`.
